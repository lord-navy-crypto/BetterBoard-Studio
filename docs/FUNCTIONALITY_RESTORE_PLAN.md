# BetterBoard functionality-preserving cleanup

Principle: simplify navigation and reuse shared sessions without removing capabilities.

Restore targets:
- keep V2 Numerical and Magnet labs as the default experience;
- restore the original advanced Numerical and Magnet workspaces as optional Advanced tools;
- preserve manual analyzer commands and saved-package workflows;
- preserve repeatability / repeated-position magnetic captures and existing scan/model workflows;
- preserve Physical Lab bridge inspection as an explicit advanced view while keeping Monitor & Data unified;
- do not remove live monitor, replay, shared hardware session, in-app analysis, or icon fixes.

A feature may move behind Advanced/Details, but it must not disappear solely for visual simplification.
