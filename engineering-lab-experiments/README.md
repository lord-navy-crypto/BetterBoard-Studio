# BetterBoard Engineering Lab Experiments

This directory contains model-oriented measurement firmware for Engineering Lab. The sketches are not generic sensor demos: each stream is designed to preserve evidence useful to a named simulation or analysis target while keeping interpretation downstream.

The initial suite contains nine experiments spanning magnetic fields, motion, vibration, rotational dynamics, photogates, ADC behavior, force, electrical power, and environmental drift.

## v2 enhancement era

The v2 effort strengthens the boundary between **measurement evidence** and **scientific interpretation**. Enhancements should improve observability, provenance, timing, synchronization, and failure visibility while preserving raw measurements and constrained-board compatibility.

See `ENHANCEMENT_V2.md`, `QUALITY_CONTRACT.md`, `DERIVED_OBSERVABLES.md`, `V2_ACCEPTANCE.md`, and `V2_REVIEW_CHECKLIST.md` for the working contract.
