# Engineering Lab v2 Success Criteria

The enhancement era succeeds when a recorded dataset can answer not only **what number was measured**, but also the questions needed to evaluate that number responsibly:

- When was it acquired?
- Which sensor/channel produced it?
- In what units and coordinate frame?
- Was the read valid and fresh?
- Which configuration and calibration assumptions were active?
- Which values are raw and which are derived?
- Can a derived value be reconstructed?
- Can two runs be compared without guessing hidden firmware settings?

The goal is not maximum firmware complexity. The goal is a short, auditable path from physical measurement to Engineering Lab model comparison.
