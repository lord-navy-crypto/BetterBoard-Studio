# Honeycomb mechanical-analogue measurement path

Recommended experimental interpretation:

mechanical honeycomb / coupled-mass structure
    -> accelerometer
    -> Arduino
    -> a(t)
    -> calibrated acceleration trace
    -> FFT / local vibration spectrum
    -> resonance / mode peaks
    -> compare against bounded Physical Lab lattice-dynamics observables

Useful observables:
- acceleration time series
- dominant resonance frequencies
- peak-frequency shifts after adding a mass defect
- response changes after weakening/removing a mechanical connection
- finite-window spectral amplitudes

Do NOT claim:
- direct graphene phonon validation
- ab-initio material validation
- atom-scale displacement measurement
- calibrated mapping from reduced units to SI without an explicit physical parameter model
